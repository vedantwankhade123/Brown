# Brown AI v1.0.1 — Official Release Notes

### What's New in v1.0.1

This update resolves the post-installation first-run onboarding flow and synchronizes in-app auto-updates with GitHub Releases.

#### ✨ Key Fixes & Improvements
- **Guaranteed First-Time Onboarding Flow**: Resolved an issue where fresh installs or reinstalls skipped the onboarding screens and went straight to the main app interface.
- **Installer Marker Reconciliation**: The NSIS Windows installer now cleanly resets setup markers during installation and reinstallation so users always experience personalization and component checks.
- **Deferred Setup State**: Onboarding marker is now written only after completing all setup steps, ensuring crash resilience and interrupted sessions resume seamlessly.
- **Top-Level Onboarding Layer**: Adjusted z-index layering to guarantee the onboarding flow remains unobscured by any background notifications or modal dialogs.
- **Unified GitHub Releases Feed**: Fixed the in-app auto-updater to track official vedantwankhade123/Brown releases for seamless background downloading and one-click upgrades.
