# Brown AI v1.0.16 — Official Release Notes

### What's New in v1.0.16

#### 🚀 Double-Send Prevention & Smooth Turn Locking
- **Synchronous Prompt Lock**: Eliminated race conditions where pressing enter or clicking send could trigger duplicate message submissions and dual simultaneous replies.
- **Auto-Disabled Send State**: Send button and input interactions are strictly disabled with clear visual feedback while Brown is actively generating or thinking.

#### 💬 Chat Session Loading & Sidebar History
- **Reliable Conversation Loading**: Clicking any recent chat session in the sidebar now instantly retrieves and renders the complete conversation history with full context, preventing empty state lockups.
- **Session Timestamps**: Recent chats in the sidebar now display clear date and time indicators below their titles for effortless navigation.

#### 📊 Robust Markdown & Table Rendering
- **Table Structure Repair**: Fixed regular expression edge cases that broke multi-column markdown tables and line breaks.
- **Pointwise Search Alignment**: Cleaned up newline handling in structured search and dining/place recommendations so rankings, bullet points, and data cards render with crisp typography.

#### 🧠 Advanced Context Engine & Hybrid RAG Retrieval
- **Entity Tracker**: Added support for resolving ordinal and anaphoric references (e.g., "the second one", "compare it") across multi-turn workflows.
- **Hybrid Search**: Enhanced document ingestion with BM25 + vector hybrid scoring for pinpoint accuracy in local knowledge bases.
- **Local Places & Dining Gating**: Improved real-time location grounding and SEO listicle filtering for local business and dining queries.

#### 📱 Mobile Companion Upgrades
- **Dynamic Thinking Indicator**: Replaced static states with informative dynamic status updates showing real-time inference steps and agent reasoning.
- **In-App Update Detection**: Integrated update prompt modal and seamless companion release sync.

#### 🎨 Desktop UI & Distribution
- **Official Setup Installer**: `Brown AI Setup v1.0.16.exe` with improved NSIS installer bundling.
- **Portable Edition**: `Brown AI v1.0.16.exe` for standalone, zero-installation execution.
- **App Badges & Polish**: Updated all in-app version indicators and status telemetry to v1.0.16.
