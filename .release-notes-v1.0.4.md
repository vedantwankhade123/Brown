# Brown AI v1.0.4 — Official Release Notes

### What's New in v1.0.4

A hardening release for the desktop app: every untrusted input the agent can reach — model output, downloaded files, LAN requests, pairing codes, file paths — now passes a real check before it can act. Alongside that, the chat window got a cleaner welcome screen and a session rail that stays out of the way until it has something to show.

#### 🔒 Security & privacy
- **Sanitized answer markup**: Markdown, HTML, SVG and math from the model are run through DOMPurify before they reach the page, so a crafted answer can no longer inject script or restyle the app. Mermaid diagrams moved to `strict` security, and the canvas viewer dropped its unsanitized raw-Markdown fallback.
- **Path blacklist that follows the truth**: junctions, symlinks and 8.3 short names now resolve to their real target before the check, so `C:\Progra~1` or a symlink into `System32` no longer slips through.
- **Risky commands always ask**: destructive wipes, script hosts (`mshta`, `rundll32`, hidden PowerShell), download-and-run chains and persistence (`schtasks`, services, Run key) now surface for approval even in Adaptive mode.
- **Guarded downloads**: model-supplied URLs must be public http(s) — loopback, link-local and raw addresses are refused — with a 200 MB ceiling, a sanitized destination path and a `basename()`-ed filename so a download cannot walk out of its folder.
- **Tighter phone pairing**: failed pairing codes are rate-limited per server (not per request), repeat requests reuse the live code instead of minting new ones, request bodies are capped, cross-origin access is limited to local dev origins, and a pairing token is bound to the LAN it was created on.
- **Location stays home**: the app no longer prefetches device coordinates on every launch — location resolves lazily, only when a request actually needs it.

#### 🖥️ Desktop interface
- **Welcome screen**: the quick-action prompts are now a plain centered list — Write or edit, Fix some code, Summarize, Brainstorm — each a full-width row with a bare arrow, replacing the card carousel.
- **Session rail on demand**: the right-hand rail starts closed and opens itself the first time Tasks, Tools, Output, Pages, Sources or the In-focus card gets real content. A manual collapse sticks for that conversation, so it never fights you.
- **One continuous surface**: the canvas behind the Settings content card and the Windows title bar now match the app slab exactly, which removes the grey seam along the card's rounded corners.

#### 📚 Documentation
- Added a plain-language project overview (`docs/READABLE.md` / `.html`), a tech-stack guide, a glossary and a 16-slide overview deck, indexed from `docs/README.md`.
