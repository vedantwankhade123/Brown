# 🌐 Antigravity Prompt: Ultron AI Agent Landing Page & Download Portal

This document contains the complete, detailed prompt to give to an **Antigravity AI Agent** on your other computer to build the official web landing page and download website for **Ultron AI Agent**.

---

## 📋 Copyable Prompt Text

Copy everything inside the box below and paste it into your Antigravity session on your other computer:

```markdown
<USER_REQUEST>
Build a world-class, modern, high-converting landing page and download portal website for "Ultron AI Agent" — an autonomous, privacy-focused offline & online local AI agent for Windows.

The website should feature rich glassmorphism aesthetics, dynamic dark mode styling, ambient glowing mesh backgrounds, smooth micro-animations, interactive feature cards, system requirement specs, and a complete downloadable software section with step-by-step Windows installation guides.
</USER_REQUEST>

## 🎨 Design & Aesthetic Guidelines
1. **Color Palette & Vibe**:
   - Background: Deep void dark background (`#0a0a0c`, `#121318`).
   - Glowing Accents: Cyan/Electric Blue (`#38bdf8`, `#60a5fa`), Emerald Green (`#34d399`), and Cyber Violet (`#c084fc`).
   - Glassmorphism: Backdrop blur (`backdrop-filter: blur(16px)`), frosted glass cards (`rgba(255, 255, 255, 0.03)` with `1px solid rgba(255, 255, 255, 0.08)` borders).
   - Typography: Google Fonts `Inter` or `Outfit` with crisp high-contrast white text.

2. **Animations & Interactive Polish**:
   - Hero section with live typing animation simulation & voice audio visualizer demo.
   - Smooth scroll navigation across sections.
   - Interactive hover cards with subtle glow borders.

## 🚀 Key Sections to Include

### 1. Navigation Header
- **Logo**: Sleek Ultron Hexagonal Shield Logo with glowing badge `"v1.0.0 Stable"`.
- **Nav Links**: Features, Architecture, Local Models, Download, Installation Guide.
- **CTA Button**: Glowing Primary `"Download for Windows (.exe)"` button with Windows logo SVG.

### 2. Hero Section
- **Badge**: `"🔒 100% Offline & Private Local Windows AI Framework"`.
- **Headline**: `"The Autonomous Local AI Agent for Windows"`.
- **Subheadline**: `"Execute local computer tasks, generate code, control system files, and chat with Google Gemini 3.0 or local Ollama models — completely on your machine."`.
- **CTA Buttons**:
  - Primary: `"Download Ultron Setup v1.0.0 (.exe)"` (Direct download link for `Ultron AI Agent Setup 1.0.0.exe`).
  - Secondary: `"Download Portable Edition"` (Link for `Ultron AI Agent 1.0.0.exe`).
- **Interactive UI Preview Card**: A mockup of the Ultron desktop application with a live voice visualizer waveform and terminal log trace stream.

### 3. Core Features Showcase Grid
- 🎙️ **Dual-Engine Voice-to-Text**: Real-time voice pitch & volume intensity visualizer with instant multimodal audio transcription.
- ⚡ **Google Gemini 3.0 & 3.5 Models**: Built-in support for `gemini-3.0-flash`, `gemini-3.0-pro`, and `gemini-3.5-pro`.
- 🦙 **Offline Ollama Local LLMs**: Auto-detects and runs local models (`llama3`, `mistral`, `qwen`, `phi3`) 100% offline.
- 💻 **Computer System Automation**: Runs terminal scripts, manages file directories, and creates applications.
- 📍 **Smart Location Awareness**: Auto-detects user city/timezone and adapts web search results dynamically.
- 🔒 **Zero Data Collection**: All conversations, memory vectors, and system traces remain strictly on your local device.

### 4. Download & Distribution Center
- **Main Download Cards**:
  - **Option 1: Windows Setup Wizard Installer (`Ultron AI Agent Setup 1.0.0.exe`)**
    - Guided installation wizard, custom directory picker, Desktop shortcut, and Control Panel Add/Remove integration.
  - **Option 2: Standalone Portable Edition (`Ultron AI Agent 1.0.0.exe`)**
    - Zero installation required — click and run instantly.
- **System Requirements Specs Table**:
  - OS: Windows 10 / Windows 11 (64-bit)
  - RAM: 8 GB minimum (16 GB recommended)
  - Architecture: x64

### 5. Step-by-Step Installation Guide (Tabbed View)
- **Tab 1: Setup Wizard Installation**
  1. Download `Ultron AI Agent Setup 1.0.0.exe`.
  2. Double-click the `.exe` file to launch the setup wizard.
  3. Select your desired installation directory (default `C:\Program Files\Ultron AI Agent`).
  4. Check *"Create Desktop Shortcut"* and click **Install**.
- **Tab 2: Connecting Ollama (Offline Models)**
  1. Download and install Ollama from [ollama.com](https://ollama.com).
  2. Run `ollama pull llama3` in command prompt.
  3. Launch Ultron — Ollama models will automatically appear in the top model selector.
- **Tab 3: Connecting Google Gemini 3.0 (Online API)**
  1. Get a free API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).
  2. Open Ultron **Settings > Models**.
  3. Paste your Gemini API key and select `gemini-3.0-flash` or `gemini-3.5-pro`.

### 6. Footer
- Links to GitHub repo, Documentation, Release Notes.
```
