# Brown AI Desktop v1.0.23

## Downloads (Windows)
- **Setup Installer** (recommended): `Brown-AI-Setup.exe`
- **Portable Edition**: `Brown-AI-Portable.exe`
- **This version**: `Brown-AI-Setup-v1.0.23.exe`

## Changes

- Models: downloading a model now shows real progress — megabytes downloaded, total size and
  speed — and Cancel actually stops the download instead of only closing the progress window.
- Models: the download catalog is paginated (12 per page) instead of growing one endless list,
  the cards were rebuilt with a grid/list switch, and the search box now opens and closes on
  demand so the list stays readable.
- Voice: choosing a Kokoro voice installs the shared Kokoro engine first when it is missing,
  reports progress on the card you clicked, and a failed download leaves the button usable
  instead of stuck on "Checking".
- Settings: Diagnostics moved out of Help into its own tab, so the local (never uploaded)
  report export is easier to find.
- Installer: it now asks whether to create a desktop shortcut. Leaving it ticked behaves like
  before; unticking it keeps Start-menu only, and an update will not re-add a shortcut you removed.
- Reliability: starting Ollama now confirms it actually came online, and reports what went wrong
  when it does not, instead of always claiming success. A model that cannot be downloaded,
  deleted mid-download, or searched for now shows the real error.
- Reliability: if Brown cannot write to your models or storage folder, it names the folder that
  is blocking it instead of failing later during a download.
- Fixes: two Settings/agent actions that threw an internal error are working again — the agent
  fetching a web page, and changing or resetting the Connectors folder in Settings.
- Security: model names and Ollama/Hugging Face paths are passed to Windows without a shell,
  so a crafted name can no longer run a command.
- Notes: installers are unsigned. SmartScreen may show a warning — choose "More info" → "Run anyway".
