# Brown AI 1.0.21

The Windows installer uses a simple black Brown logo panel and white welcome/completion pages. The uninstaller uses the same artwork.

- Longer conversations retain more short turns within the existing text budget. Explicit references to facts supplied by the user can retrieve older user messages beyond the recent window; follow-ups retain conversation context even if the planner incorrectly disables it.

- Uninstall removes application files while keeping chats, downloaded models, connectors, settings and unrelated files in the installation folder. Locked application files stop removal before uninstall registration is cleared.
- Installer cancellation and failure restore install-relative storage moved aside for compatibility with older uninstallers. An existing recovery backup blocks a new upgrade instead of overwriting it.
- Shortcut creation follows the standard installer preferences. Cleanup no longer recursively deletes Start Menu folders.
- Update downloads accept explicit HTTPS GitHub release hosts, validate installer checksums, isolate temporary downloads, clean interrupted downloads, compare semantic versions and keep Brown open if installer launch immediately fails.
- Help includes **Export local diagnostics**. Reports contain app/Electron/runtime versions, model names/digests, available generation settings, timings and error codes for recent requests in the current app session. No upload occurs.
- Conversation content is excluded by default. To include the current chat, select the checkbox and confirm the native dialog. The choice resets after each export. Credential redaction is best effort; review any opted-in conversation before sharing.

## Preview and verification

`output/Brown-Installer-Preview-v1.0.21.exe` previews the wizard without installing application files, registry entries or shortcuts. Its completion wording demonstrates the production screen; it does not mean Brown was installed.

Artwork is generated by `node scripts/build-installer-art.cjs`. Shared copy is in `build/installer-ui.nsh`; preview pages are in `build/installer-preview.nsi`. Compile the preview with the cached electron-builder NSIS compiler. Production builds use the same artwork and shared copy.

Validation includes the automated suite, Electron chat regression test, diagnostic default privacy/explicit consent/cancel/write-error tests, and a compiled NSIS removal fixture that preserves saved data and unrelated files. A disposable fixture is not a substitute for clean-machine installation, upgrade and uninstall testing across supported Windows versions. Installer launch confirmation is not confirmation that a later upgrade completed successfully.

The final package in `dist-desktop-v1.0.21-verified` built successfully. Its packaged diagnostic/updater/IPC sources match the workspace and include the direct semver dependency. A packaged smoke test with installed `gemma4:latest` passed using an isolated temporary profile. Metadata-only export validation detected the local Ollama runtime and four installed models without conversation content. The installer was not installed or published during verification.

That earlier candidate is superseded by `dist-desktop-v1.0.21-ready`, which includes the longer-conversation correction found during follow-up validation. Use the candidate-readiness report for the current artifact hashes and remaining release gates.
