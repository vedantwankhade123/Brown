# Brown AI Desktop v1.0.22

## Downloads (Windows)
- **Setup Installer** (recommended): `Brown-AI-Setup.exe`
- **Portable Edition**: `Brown-AI-Portable.exe`
- **This version**: `Brown-AI-Setup-v1.0.22.exe`

## Changes

- Security: untrusted file, web, and tool output is now treated as data at runtime. A write or
  command that follows it asks for your approval even in Full Autonomous Mode, and a stored
  "Always allow" no longer bypasses that check. File browsing and reads are never interrupted.
- Security: the permission-mode picker (Prompt Every Action / Smart Auto-Approval / Full
  Autonomous) now actually controls agent actions — previously it had no effect on the agent loop.
- Security: the Files & folders capability now defaults to Ask instead of Always.
- Agent: every run records a privacy-safe evidence ledger (tool results, verification outcomes,
  taint status) that the evaluation harness can replay.
- Models: hardware-aware model recommendations using real RAM and GPU VRAM plus the models you
  actually have installed, replacing the old memory-only guess.
- Stability: asar integrity gate in the release pipeline; diagnostics export; storage isolation
  tests.
- Notes: installers are unsigned. SmartScreen may show a warning — choose "More info" → "Run anyway".
