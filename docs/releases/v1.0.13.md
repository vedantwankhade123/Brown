# 🚀 Ultron AI v1.0.13 — Robust Setup, Installer Branding & Storage Fixes

### 📦 Key Highlights & Improvements

- 🛠️ **Robust Installation & File Overwrites**:
  - Installer forcefully cleans up running background processes before setup and uninstall, preventing locked binary and `.node` files during version upgrades.
  - Automatically replaces all existing application files with the latest build.
- 🎯 **Accurate Shortcut Targeting**:
  - Fixed shortcut resolving issues where older versions or `win-unpacked` binaries were targeted.
  - Cleaned up stale shortcuts across user profiles, OneDrive desktop folders, public desktop, and Start Menu.
  - Shortcuts now strictly point to `$INSTDIR\Ultron AI.exe`.
- 🎨 **Setup Wizard Branding & Logo**:
  - Added official Ultron AI cybernetic branding sidebar on Welcome and Finish screens of the NSIS installer wizard.
  - Added header logo branding in setup wizard dialogs.
  - Embedded crisp native Windows `.ico` format for window taskbar and titlebar.
- 📁 **Clean Storage Architecture**:
  - Eliminated duplicate `Ultron-AI` folder creation on root drives.
  - Persistent data, memories, and conversations now cleanly default to `%LOCALAPPDATA%\UltronData`.
