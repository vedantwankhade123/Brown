# Brown AI Desktop v1.0.7

## Update and installation fixes
- Validate installer checksums and file size before installation, and reject interrupted downloads.
- Start the installer before exiting Brown; launch failures keep Brown open and allow retry.
- Install into the existing application folder and request an automatic relaunch.
- Remove installer process-tree termination that could kill the updater's own installer.
- Protect install-relative chats, settings, connectors, models and onboarding state from older uninstallers during upgrades.
- Coalesce simultaneous update checks and downloads, and show one notification per update state.
- Publish update metadata whose filenames and hashes match the uploaded installer.
- Website download links always follow the latest published release.

## Downloads
- Brown-AI-Setup.exe: Windows installer and in-place updates.
- Brown-AI-Portable.exe: portable edition. Portable users should replace the executable manually.

## Recovery from an older failed updater
If Restart and Install still fails in an older installed build, download Brown-AI-Setup.exe from https://usebrown.online/download and run it once over the existing installation. The improved updater is included in v1.0.7.
