# Brown AI v1.0 — Official Release Notes

### What's New in v1.0

First unified production release of **Brown AI** for Windows Desktop and Android Mobile.

#### Desktop (Windows)
- Setup installer and portable executable
- Local offline AI with Ollama / cloud providers
- Voice (Kokoro TTS + Whisper STT), MCP tools, and desktop automation
- In-app auto-updates from Brown-Releases

#### Mobile (Android)
- On-device GGUF model chat
- Kokoro TTS + speech input
- In-app update checks against the same Brown-Releases feed
- Brown B launcher icon
