# Brown AI v1.0.2 — Official Release Notes

### What's New in v1.0.2

The biggest release since launch: Brown now works as an agent inside a real browser, the chat window keeps its own workspace rail, and answers are properly typeset. Desktop and mobile also pair over Wi-Fi with a scannable QR code and share voice.

#### 🤖 Agent & Workspace
- **Built-in agent browser**: Brown opens pages, reads them and acts on them in a docked browser pane you can pop out, with an approval prompt before every action and strict public-address-only networking.
- **Session rail**: Tasks, Tools, Output, Pages and Sources now live in one right-hand rail that follows the current conversation, with per-section state that survives reloads.
- **In-chat task checklist**: multi-step plans render as a live checklist instead of a wall of text.
- **Docked context bar**: project picker, @-mentions and file citations sit next to the composer; uploads appear under Sources only once sent.

#### 🧠 Answers
- **Rewritten math typesetting**: one shared KaTeX pass repairs LaTeX before Markdown touches it, so equations render inline and progressively while streaming.
- **Rich output**: expanded chart engine (area, scatter, histogram, boxplot, radar, multi-series) plus unlocked advanced Mermaid diagram types.
- **Smarter model routing**: requests are classified by intent, so diagrams and heavy text go to capable models while everyday chat stays fast and local. Every path streams.

#### 🖥️ Desktop
- **Settings rebuilt**: Sounds, Performance and Storage redesigned around one card system, with real-time GPU / memory / CPU telemetry backed by new system-info and storage-usage IPC.
- **App speed control**: a single three-way toggle (Battery saver · Balanced · High performance) replaces the old runtime-profile dropdown.
- **Reliable auto-updates**: the updater falls back to direct GitHub download and raises native Windows notifications when an update is available or ready.
- **Light theme pass**: every rebuilt surface was audited in light mode.

#### 📱 Mobile & Sync
- **QR pairing, rebuilt**: real scannable QR from the desktop, code-only verification, 120-second auto-regenerating codes and automatic port fallback.
- **Real voice**: offline Kokoro text-to-speech and Whisper speech-to-text run on the desktop and serve the phone; recordings capture true PCM audio.
- **On-device inference + updates**: quantized GGUF models run locally, and the app now detects and installs new APKs from GitHub Releases with in-app notifications.
- **UI**: ChatGPT-style chat screen with a header model picker, reworked drawer, empty states, keyboard-aware composer, animated Brown mark.
